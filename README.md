## Overview

Sicada Digital is a modern web project built as a reusable, responsive frontend experience rather than a static one-page site.

The project is structured around component-driven React development, routed pages, utility-first styling, and a lightweight Vite toolchain suitable for fast iteration and deployment.

## Technology

| Area | Technology |
|---|---|
| UI | React 19 |
| Build tool | Vite 8 |
| Styling | Tailwind CSS 4 |
| Routing | React Router 7 |
| Backend / services | Firebase |
| Icons | Lucide React |
| Code quality | ESLint |

## Frontend Architecture

```text
Browser
   │
   ▼
React Application
   │
   ├── Routed Pages
   ├── Reusable UI Components
   ├── Responsive Layout System
   ├── Tailwind Design Layer
   └── Firebase-connected Services
   │
   ▼
Vite Build Pipeline
```

The project favors a lightweight frontend stack with minimal framework overhead while retaining clear separation between presentation, navigation, and service integrations.

## Design Goals

Sicada is developed around a few practical frontend principles:

- responsive layouts across desktop and mobile;
- clear visual hierarchy;
- reusable React components;
- consistent design tokens and spacing;
- fast client-side navigation;
- maintainable styling through Tailwind CSS;
- a small build surface for inexpensive deployment and iteration.

## Local Development

### Requirements

- Node.js compatible with the current Vite toolchain
- npm

### Setup

```bash
git clone https://github.com/mkraja826/Sicada.git
cd Sicada
npm install
npm run dev
```

### Quality Checks

```bash
npm run lint
npm run build
```

### Production Preview

```bash
npm run preview
```
